# Historical analysis example: Instagram Likes

This folder preserves a completed earlier 202-handler Instagram Likes analysis and its source files as a method example. It is not the current handler inventory or the actual product being built. Do not copy its ProductDefinition assumptions, IDs, or handler counts into current work.

The actual service roadmap is `../../catalog.json`; the current handler evidence is in `../../handler services.json`, and catalog-to-handler ID mappings are in `../../catalog-handler-service-ids.json`. Actual-service analysis belongs under `../../analysis/`, while canonical definitions belong under `../../products/` after analysis approval.

Read `analysis.md` for the historical multi-view breakdown and `decisions-and-pitfalls.md` for process lessons. The files under `source/` are historical inputs only.
